# Moretom Keyboard (English Right-to-Left for Android)

**Moretom** is a custom Android system keyboard that uses the standard English QWERTY Latin alphabet and writes from **right to left** in any app.

## Features
- **Language Name:** Appears as **Moretom (English RTL)** in your Android keyboard switcher.
- **Spacebar Switching:** Long-press the spacebar in Gboard to switch to **Moretom**, and long-press the **Moretom** spacebar to switch back to Gboard.
- **Universal RTL Typing:** Works in WhatsApp, Instagram, Discord, Chrome, Notes, and games.
- **RLO Toggle Button:** Tap `RLO` on the top row if you also want right-aligned visual paragraphs via Unicode `U+202E`.

---

## Option A: Build the APK on Your Phone (No PC Needed)
1. Extract `Moretom-Keyboard.zip` on your phone.
2. Create a free account at [github.com](https://github.com) and create a new repository (e.g., `moretom-keyboard`).
3. Upload the extracted files (including the `.github` folder) to the repository.
4. Open the **Actions** tab in your GitHub repository — it will automatically build **Moretom-Keyboard-APK** in ~2 minutes.
5. Download the `Moretom-Keyboard-APK` zip, extract `app-debug.apk`, and tap it to install on your Android phone.

## Option B: Build with Android Studio (PC / Mac)
1. Extract `Moretom-Keyboard.zip` and open the folder in **Android Studio**.
2. Click **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** (or click **Run** with your phone connected via USB).

---

## How to Enable & Use
1. Open the **Moretom** app on your phone and tap **1. Enable Moretom in Keyboard Settings** (turn the **Moretom** toggle ON).
2. Open any app (like WhatsApp or Notes) so your normal **Gboard** pops up.
3. **Press and hold the spacebar** on Gboard and select **Moretom**.
4. Type normally with QWERTY — letters flow from **right to left**. Long-press the **Moretom** spacebar anytime to switch back to Gboard.
